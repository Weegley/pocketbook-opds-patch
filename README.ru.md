# PocketBook OPDS Patch

[English](README.md) | **Русский**

**Только PocketBook 632 (Touch HD 3), прошивка U632.6.11.2001.**

Включает вторую строку под заголовками навигационных записей штатного OPDS-клиента — текст каталога из `content type="text"`. В [inpx-web](https://github.com/bookpauk/inpx-web) у папки самой книги это авторы; у других папок — например, количество книг. Навигация **папка книги → раздел «Книга» → подробности/скачивание** сохраняется. Менять сервер не нужно.

## Скачать и использовать

Приложения находятся в [последнем релизе](https://github.com/Weegley/pocketbook-opds-patch/releases/latest).

| Приложение | Для чего выбрать |
| --- | --- |
| **Online libraries.app** | Отдельный ярлык, сразу открывающий штатный OPDS. Без root, системной установки и перезагрузки. |
| **Non-rooted patch.app** | Установка/удаление исправления в системном OPDS. При необходимости получает root и удаляет его после успеха. |
| **Rooted patch.app** | Установка/удаление того же патча через существующий поддерживаемый root от pbjb, с сохранением root. |

1. Скопируйте выбранный `.app` в `applications/` внутренней памяти ридера. Дополнительные папки не нужны.
2. Безопасно отключите USB и запустите файл из меню приложений.
3. Online libraries откроет OPDS. Установщик предложит **Установить** или **Удалить** в зависимости от текущей библиотеки; подтвердите действие и дождитесь **одной перезагрузки**.

**Non-rooted удаляет и ранее установленный root — после отдельного подтверждения. Чтобы сохранить root, выбирайте Rooted.** Rooted требует совместимый `/mnt/secure/su` от pbjb; произвольные другие helper не поддерживаются.

При русском интерфейсе ридера диалоги русские, при остальных языках — английские. Проприетарная OPDS-библиотека **не включена**: приложения создают проверенную копию из оригинала самого ридера. Сохраните свои данные, зарядите устройство и не прерывайте системную установку.

## Удаление

- **Системный патч:** запустите тот же установщик, выберите **Удалить** и дождитесь перезагрузки. Удаление самого `.app` патч не удаляет.
- **Online libraries:** закройте OPDS и удалите `.app`. При желании удалите кэш: `system/.opds-authors-611-open/standalone-open-v9/`.

При ошибке сохраните `OPDS_*.log` из внутренней памяти и следуйте [инструкции восстановления](docs/RECOVERY.md). Незавершённую операцию продолжайте тем же установщиком той же версии.

## Собрать самостоятельно

Windows:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Debian/Ubuntu x86-64:

```sh
sh build.sh
```

Python, Zig и pbjb скачиваются автоматически с проверкой закреплённых SHA-256, только внутрь проекта. Глобальной установки нет. Приложения и суммы появятся в `dist/`. Владелец подтвердил автоматическую сборку на Windows/Linux и работу всех трёх приложений на ридере.
